# 📊 Product Operations & Performance Dashboard

A data analytics project that monitors project execution, employee workload, task status, and overall operational performance using SQL, Python, Pandas, and Excel.

## 🚀 Project Overview

This project simulates a Product Operations team managing multiple client projects. The workflow includes:

- SQL database creation and querying
- Data cleaning using Pandas
- KPI calculation
- Employee workload analysis
- Project performance tracking
- Interactive Excel dashboard

## 🛠 Technologies Used

- MySQL
- Python
- Pandas
- Matplotlib
- Excel

## 📈 Key KPIs

- Total Tasks
- Completed Tasks
- Delayed Tasks
- Completion Rate

## 📁 Project Structure

```text
SQL/                → SQL queries
analysis.py         → Python analysis
Dashboard.xlsx      → Excel dashboard
*.png               → Generated charts
```
